# Changelog

## 0.1.0

Initial standalone extraction from DOOM Classic Browser.

- Verified streaming and multipart asset loading with SHA-256 and cancellation.
- Keyboard and virtual input aggregation with independent source lifetimes.
- Explicit readiness and serialized engine lifecycle transitions.
- IndexedDB storage that confirms writes after transaction completion.
- Scoped, versioned offline service-worker generation.
- TypeScript declarations, English Canvas example, and Node/browser tests.

The library has no runtime dependencies and includes no game assets or renderer.
The original GPL-2.0-or-later licensing is preserved.
